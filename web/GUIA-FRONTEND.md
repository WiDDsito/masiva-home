# Guía del frontend

Desde esta carpeta, ejecuta `npm ci` para instalar las dependencias y `npm run dev` para iniciar Vite. El [README principal](../README.md) explica la compilación y la integración con WordPress.

Para cambios en el catálogo o el pago, consulta el [flujo de compra](../plan/arquitectura-y-compra.md) y las [actualizaciones recientes](../docs/actualizaciones.md).
